The program

What follows is the entire program — some 2,400 lines of FORTRAN 77, the same code that runs when you press RUN on the red-dwarf page. It is the direct descendant of the 1964 deck on the companion listing: the same Henyey solver, now in double precision, carrying the published physics of the 1993 and 1997 papers — the SCVH equation of state, the molecule-and-grain opacities, the seven-species reaction network, the case-B atmosphere, and the Hayashi-track starts. The notes in the margin say what each part is doing, where it comes from in the literature, and — where it applies — what it took to make it converge. Begin with the flow of the calculation, then read the listing itself. The boxes of the flow chart are links into the code.

Fixed form still: columns 1–5 hold statement labels (printed red), column 6 marks a continuation, columns 7–72 carry the statement — but the dialect is FORTRAN 77, with block IF and double precision throughout. Lines whose number is red carry a note in the margin; on a narrow screen the notes move inline. The program compiles with any Fortran compiler in legacy mode, and the browser copy was translated to C by a freshly built f2c — the venerable translator, itself a piece of the era.
